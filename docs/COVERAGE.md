## Each gap

### set_notation

**Set builder and set operations** (tier C, 14,359 relations on 3,932 pages). `Hg = \{h \cdot g \mid h \in H\}`, `\{1, 2, \ldots, n\}`.

**What a contribution looks like.** Definitions and set equalities; not identities between computable expressions. Correctly skipped. A contributor could make the skip reason precise and cheap (it is currently the largest single bucket).

Examples:

- *Pi*: `\{\dots,-2\pi i, 0, 2\pi i, 4\pi i,\dots\} = \{2\pi ki\mid k\in\mathbb Z\}`
- *Euclidean algorithm*: `\{ r_{-2} = a,\ r_{-1} = b,\ r_0,\ r_1,\ \cdots,\ r_{n-1},\ r_n = 0 \}`
- *Group (mathematics)*: `\Z = \{\ldots,-4,-3,-2,-1,0,1,2,3,4,\ldots\}`
- *Group (mathematics)*: `X=\{x,y,z\}`
- *Group (mathematics)*: `R=\{\mathrm{id},r_1,r_2,r_3\}`
- *Affine symmetric group*: `\{u(1), \ldots, u(n) \} = \{1, 2, \ldots, n \}`

### superscript_label

**Superscripts that are labels, not powers** (tier B, 11,979 relations on 3,130 pages). `\omega_1^n`, `K_n^M(F)`, `x^{(k)}`. The translator refuses the whole formula when it cannot tell a power from an index.

**What a contribution looks like.** Better disambiguation: a superscript on a symbol that also carries a subscript, or that appears in `(k)` form, or that is never used as a power elsewhere on the page, is a label; rewrite it into the symbol name instead of refusing. Measure on the review fixtures: label misreads were the second-largest false-positive cause in run 1, so precision must not drop.

Examples:

- *Dirac delta function*: `\delta(x) = \Delta_x^{(n+k)/2} \int_{S^{n-1}} g(x\cdot\xi)\,d\omega_\xi.`
- *Cardinality*: `\vert A \vert^{\vert B \vert} := \vert A^B\vert`
- *Cantor's first set theory article*: `\omega_1^1 < p < q < \omega_1^n`
- *Cantor's first set theory article*: `p < p_1 < q_1 < \omega_k^n < q.`
- *Cantor's first set theory article*: `\ p_1 < \omega_{k_1}^n < q_1,`
- *Cantor's first set theory article*: `p_1 < p_2 < q_2 < \omega_{k_1}^n < q_1.`

- *Affine symmetric group*: `w_{441} = [1 + 4 - 3, 2 + 4 - 3, 3 + 1 - 3] = [2, 3, 1]`

### ellipsis

**Series and products written with an ellipsis** (tier A, 9,676 relations on 3,031 pages). `1 + \frac{1}{4} + \frac{1}{9} + \cdots = \frac{\pi^2}{6}`, `z - z^3/3 + z^5/5 - \cdots`. Written-out series are how most articles state a famous identity; they are real, checkable claims.

**What a contribution looks like.** A pattern recogniser in the translator that turns `a_1 + a_2 + a_3 + \cdots` (and `\cdots + a_n` finite forms) into `Sum(term(k), (k, 1, oo))` when the first three or four terms fix a term formula (powers, factorials, alternating signs, odd/even indices). Refuse anything ambiguous. Fixtures: the Pi, Basel problem and Taylor series pages.

Examples:

- *Pi*: `\frac{\pi^2}{6} = \frac{1}{1^2} + \frac{1}{2^2} + \frac{1}{3^2} + \frac{1}{4^2} + \cdots`
- *Archimedes*: `\sum_{n=0}^\infty 4^{-n} = 1 + 4^{-1} + 4^{-2} + 4^{-3} + \cdots = {4\over 3}. \;`
- *Logarithm*: `\ln (n!) = \ln (1) + \ln (2) + \cdots + \ln (n).`
- *1 − 2 + 3 − 4 + ⋯*: `1-2+3-4+\cdots=\frac{1}{4}.`
- *1 − 2 + 3 − 4 + ⋯*: `1-2x+3x^2-4x^3+\cdots = \frac{1}{(1+x)^2}.`
- *1 − 2 + 3 − 4 + ⋯*: `\frac12 a_0-\frac14\Delta a_0 +\frac18\Delta^2 a_0 -\cdots = \frac12-\frac14.`

### matrix

**Explicit matrices** (tier A, 9,106 relations on 1,831 pages). `\begin{pmatrix} 1 & i \\ i & 1 \end{pmatrix}` with numeric or symbolic entries, often equated to a product or inverse.

**What a contribution looks like.** Extend the translator to build `sympy.Matrix` for `pmatrix`/`bmatrix`/`vmatrix` blocks, and the verify stage to evaluate matrix-valued identities entrywise (lambdify over the entries; compare shapes, then every entry). Vectors in `\mathbf{v}` notation belong to the same project (see vector algebra).

Examples:

- *Quantum mechanics*: `B = \frac1{\sqrt2}\begin{pmatrix} 1 & i \\ i & 1 \end{pmatrix}`

- *Matrix (mathematics)*: `\det \begin{bmatrix}a&b\\c&d\end{bmatrix} = ad-bc.`
- *Ordered Bell number*: `a(n)=\sum_{k=0}^{n-1} 2^k \left\langle\begin{matrix} n \\ k \end{matrix}\right\rangle=A_n(2),`

**What a contribution looks like.** Mostly vectors and matrices (see above). Once typed objects exist, `\mathbf{AB}` is a product of two typed symbols.

Examples:

- *Laplace–Runge–Lenz vector*: `\hat l_{\mathbf p }=(\mathbf p \mathbf \nabla_{\mathbf p} )`
- *Commutative property*: `\mathbf {ij}= -\mathbf {ji}`
- *Matrix (mathematics)*: `\bold{AB} \ne \bold{BA}.`
- *Matrix (mathematics)*: `(g \circ f)(\bold x) = g(f(\bold x)) = g(\bold{Ax}) = \bold B(\bold {Ax}) = (\bold{BA}) \bold x.`
- *Newton's laws of motion*: `- \frac{\partial S}{\partial t} = H\left(\mathbf{q}, \mathbf{\nabla} S, t \right).`
- *Markov chain*: `\mathbf{QP} = \mathbf{Q}.`

### sup_inf

**Suprema, infima, limsup** (tier B, 2,951 relations on 1,064 pages). `\frac{1}{R} = \limsup_{n\to\infty} |c_n|^{1/n}`, `\|P_V\| = \sup_{x \neq 0} \frac{\|P_V x\|}{\|x\|}`.

**What a contribution looks like.** Suprema over a finite explicit set are evaluable; over a continuum they usually are not. Low yield; skip cleanly.

Examples:

- *Vector space*: `\|\mathbf{x}\|_\infty := \sup_i |x_i| \qquad \text{ for } p = \infty, \text{ and }`
- *Hilbert space*: `\|\varphi\| = \sup_{\|x\|=1, x\in H} |\varphi(x)| \,.`
- *Hilbert space*: `\lVert A \rVert = \sup \bigl\{\| Ax \| \mathrel{\big|} \| x \| \leq 1 \bigr\}\,.`
- *Hilbert space*: `\sum_{b \in B} \left|x (b)\right|^2 = \sup \sum_{n=1}^N \left|x(b_n)\right|^2`
- *Big O notation*: `\inf_{n \in D} \frac{f(n)}{g(n)} > 0`
- *Reinforcement learning*: `V^*(s) = \max_\pi \mathbb{E}[G\mid s,\pi]`

## Beyond the translator

- **Definition propagation.** 50,850 formulas define a symbol and 27,052 use a page-specific function. When a page says `f(x) = x^2 + 1` and later `f(2) = 5`, substituting the definition makes the second checkable. A page-level symbol table in Semantics is the single largest coverage project that touches no LaTeX parsing.
- **Other languages.** The extract stage takes a language code; German, French, Russian and Chinese Wikipedia each have their own `<math>` corpora with their own errors, and the pipeline has never been run on them.
- **Other corpora.** Anything with LaTeX and prose: the DLMF, arXiv abstracts, textbooks, lecture notes, the formulas in an LLM's draft answer (that is what the MCP server does).
- **Review.** 756 identities came back INCONCLUSIVE in the last pass. Each one a person resolves is either a new confirmed error or a cause-tagged false positive that becomes a rule.
